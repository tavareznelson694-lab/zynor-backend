# 🎵 Zynor Membership Backend - Complete Setup Guide

## What You Have

- server.js - Your secure payment server (Node.js + Express + Stripe)
- package.json - Dependencies
- .env - Your secret keys (never share this!)
- frontend.html - Updated frontend that connects to your backend

---

## 🚀 Quick Start (Local Testing)

### Step 1: Install Dependencies

```bash
cd zynor-backend
npm install
```

### Step 2: Update .env File

Open .env and replace the placeholder values with your real Stripe keys.

### Step 3: Run Backend Locally

```bash
npm start
```

---

## 🌐 Deploy to Railway

1. Go to railway.app
2. Connect your GitHub repo
3. Add environment variables from .env
4. Deploy!
